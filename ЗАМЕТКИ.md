# Заметки к продолжению

Состояние на 21 августа 2026, конец сеанса. Писалось, чтобы продолжить
с любой машины, не восстанавливая контекст.

## Где остановились

**Все 52 элемента принимают данные пользователя.** Это главное, что сделано
за день: утром принимали 29.

Работа идёт в ветке `elements-data`. `main` остаётся на `68c12ec` и не тронут —
слияние впереди, после того как закроются задачи качества.

```bash
npm install
npm run check     # 676 пар, сличение с эталонным слепком
npm run data      # данные доходят до разметки, элемент подстраивается
npm run smoke     # сервер настоящим MCP-клиентом по stdio
npm run host      # условия запуска: чужой каталог, урезанное окружение
npm run find      # появится в задаче 10: качество поиска на 25 запросах
```

Все обязаны заканчиваться без сбоев. `npm run check` обязан сказать
**«разошлись 0»** — это и есть гарантия, что образцы не поехали.

## С чего начать в следующий раз

**Наряд 8 закрыт без независимой проверки.** Все прочие семь нарядов проходили
её обязательно: свежий агент перемерял утверждения отчёта своими руками
и трижды находил то, чего исполнитель у себя не видел — арифметическую ошибку
в композиции `cycle`, плоские столбцы `column` на малых значениях, ложное
предупреждение при верном вызове.

Восьмой этой проверки не получил: сеанс прерывался, и полный круг был бы ещё
одним долгим заходом. Ведущий сверил ключевые утверждения измерением, но это
не то же самое — сверял тот, кто наряд и писал.

**Поэтому первое дело следующего сеанса — проверить наряд 8**, а не браться
за девятый. Что проверять:

- седьмая проверка ловит оба воспроизведения (`wf` с отрицательным накоплением,
  `bub` с `x=-50`) и не даёт ложных срабатываний на 676 образцах;
- обе пересборки эталона затронули ровно свои пары — `micro` и `divider`,
  и ничего кроме;
- число оставшихся замечаний из 61 — названо ли оно и сходится ли с замером;
- зажим `bub.x`/`bub.y` не сломал раскладку при законных значениях.

Диф для проверки собирается так:

```bash
bash "$SDD/scripts/review-package" PLAN.md <база> HEAD
```

где `$SDD` — каталог навыка subagent-driven-development, а `<база>` — коммит
перед первым коммитом наряда 8.

## Что читать первым

`PLAN.md` — тринадцать задач, из них семь закрыты. У каждой сказано, **чьё
она лицо**: человека с задачей, модели-сборщика, хоста, ведущего или зрителя
слайда. Если лицо назвать нельзя, задача, скорее всего, лишняя — так с плана
сняли HTTP-транспорт.

`ТЗ.md` — постановка и раздел «Кто пользуется сервером» с разбором пяти
действующих лиц. Главное правило: **человек инструментов не видит никогда**.
Узнал слово `fmatrix` — конструкция сломалась.

## Главное правило работы с elements.js

Функции отрисовки принимают данные вторым необязательным аргументом.
**Без данных разметка обязана совпадать побайтово с прежней.**

Гарантию держит `tools/baseline.json` — слепок sha1 всех 676 пар.

```bash
npm run check        # сличить: «разошлись 0» — всё цело
npm run baseline     # ПЕРЕСОБРАТЬ слепок
```

**Пересборка за день случалась четырежды, и каждый раз по отдельному решению:**

| что менялось | пар | кто решал |
|---|---|---|
| `chip()` перестал рисовать зашитое «+23%» | 1 | владелец, спрошено явно |
| `column` — шкала от максимума вместо пола в 100 | 13 | владелец, спрошено явно |
| `area` — то же самое | 13 | ведущий, по прецеденту `column` |
| `micro` и `divider` — зазоры (задача 8) | 19 | ведущий, заранее |

Порядок, который сложился и работает: исполнитель доводит правку до состояния
«эталон разошёлся ровно в тех парах, что ожидались», называет их **поимённо**
и останавливается. Пересобирает ведущий, проверив список программно.
Разошлась чужая пара — разбираться, а не узаконивать.

## Соглашение об образцах

Образец каждого элемента лежит в константе `ОБР_<ид>` рядом со своей функцией
и подключён к каталогу `CATS` четвёртым элементом кортежа. Пятым идёт
необязательная оговорка — она есть только у `timeline`.

**Литерал не должен встречаться дважды.** На этом спотыкались десять раз,
в двух разных формах:

```bash
grep -n "==null?'[^']\+'" src/elements.js    # запасное значение в тернарнике
```

и глазами: строка из `ОБР_x`, встретившаяся в теле той же функции второй раз.
Цвета берутся из стиля `s` и в образец не входят.

## Что выяснилось за день и стоит помнить

**Живой сервер держит код на момент запуска.** Node кэширует модули. После
каждого закрытого наряда — `/mcp` и переподключить `svg-library`, иначе
проверяете вчерашний код. Поймало это предупреждение, сделанное совсем
для другого случая.

**Предупреждение при верном вызове обесценивает все остальные.** Дважды
за день это был решающий довод: не закрывать документацией зазор `journey`
и починить ложное «поле структура не передано».

**Сомнения исполнителей ценнее их основной работы.** Шесть настоящих дефектов
за день нашлись именно так, а не проверками: выдуманное число в `retro`,
чужой ответ под чужим вопросом в `faq`, плоские графики у `column` и `area`,
пустой пример у `vec`, ложное предупреждение. В каждый наряд теперь входит
строка «сомнения приветствуются» с перечнем уже найденного.

**Проба, которую не видели падающей, ничего не гарантирует.** Утром проверка
имён инструментов покрывала половину нужного и пропустила ошибку, уронившую
весь сервер вместе с чужими MCP-серверами сессии.

**Пересказ договора своими словами расходится с договором.** Шесть раз за день
план ошибался в типах и формах полей. Источник истины — `spec/elements.json`,
план лишь его пересказ.
