# Заметки к продолжению

Состояние на 20 августа 2026. Писалось, чтобы продолжить с любой машины,
не восстанавливая контекст.

## Где остановились

Сервер и проверки готовы и работают. Из 52 элементов **29 принимают данные**,
23 пока рисуются образцом и честно об этом предупреждают.

```bash
npm install
npm run check     # 676 пар, шесть проверок, сличение слепка
npm run data      # данные доходят до разметки, элемент подстраивается
npm run smoke     # сервер настоящим MCP-клиентом по stdio
```

Все три должны заканчиваться без сбоев. `npm run check` обязан сказать
**«разошлись 0»** — это и есть гарантия, что образцы не поехали.

## Главное правило работы с elements.js

Функции отрисовки принимают данные вторым необязательным аргументом.
**Без данных разметка обязана совпадать побайтово с прежней.**

Гарантию держит `tools/baseline.json` — слепок sha1 всех 676 пар, снятый
с исходного кода до правок. Он лежит в репозитории именно для того, чтобы
сличение работало на другой машине.

```bash
npm run check        # сличить: «разошлись 0» — всё цело
npm run baseline     # ПЕРЕСОБРАТЬ слепок
```

`npm run baseline` затирает эталон. Запускать только тогда, когда отрисовка
образца изменена намеренно и вы готовы это утвердить. Случайный запуск
уничтожает доказательство совместимости, и заметить это будет уже нечем.

## Как переводить оставшийся элемент

Порядок, отработанный на 29 функциях:

1. Собрать зашитое содержимое в один массив в начале функции.
2. Добавить второй аргумент: `function elX(s, дан)`.
3. Подставить данные через `ряды(дан && дан.поле, образец, максимум)`
   и `строка(дан && дан.поле, образец)` — образец остаётся значением
   по умолчанию, иначе побайтовое совпадение потеряется.
4. Имена полей брать **из договора** в `spec/elements.json`, не выдумывать.
5. Подписи пропустить через `ужать` (одна строка) либо `ужатьНабор`
   (единый кегль на ряд).
6. Если число рядов переменное — считать визуальный низ и звать `рост()`,
   отрисовку закрывать `wrapSvgH(s, o, hh)` вместо `wrapSvg`, фон рисовать
   `frameH(s, hh)` вместо `frame`. При hh = 190 они совпадают побайтово.
7. `npm run check` — «разошлись 0». Потом добавить элемент в `Д`
   внутри `tools/data-check.js` и прогнать `npm run data`.

Порог подгонки выводить из геометрии, а не подбирать константой: на этом
уже обожглись дважды — рост холста упирал содержимое в кромку, а порог,
посчитанный для полосы в 9px, ломался у retro с полосой в 10px.

Сервер править не нужно: он сам сличает результат с отрисовкой без данных
и снимает предупреждение, как только элемент начинает данные принимать.

## Открытые вопросы

1. **Сервер в Claude Desktop живьём не проверялся.** Это единственный пункт
   приёмки, который нельзя измерить скриптом. Конфиг:
   ```json
   { "mcpServers": { "svg-library": {
       "command": "node",
       "args": ["C:/Users/Alexey/Documents/besupply/deckcraf-mcp/src/index.js"] } } }
   ```
   После правки `claude_desktop_config.json` перезапустить Claude Desktop.
   Если инструменты не появились — смотреть stderr процесса, сервер пишет
   туда строку о числе элементов и стилей при старте.

2. **Два замечания данными не лечатся** — видны в `npm run data`:
   - `aurora/bars` — тёмный акцент подписи поверх поля. Болезнь стиля:
     у Aurora акценты намеренно тёмные ради читаемости на фигурах.
   - `retro/cycle` — подпись квадранта подходит к кольцу ближе 10px
     на длинном тексте: у retro подпись вынесена на 22px от кольца,
     и длинная строка достаёт до дуги.

   Оба не блокируют отрисовку, оба честно попадают в `предупреждения`.

3. **Проверки не молчат и на образцах** — 61 замечание, в основном
   пограничное (15.9px при норме 16). Разбирать не обязательно, но
   при правках стоит смотреть на прирост, а не на общий счёт.

## Что решено и почему

Развёрнуто — в `ТЗ.md`. Коротко:

- **Данные заходят внутрь функции отрисовки.** Подставить текст снаружи
  нельзя: у диаграмм подпись и геометрия берутся из одного числа, и замена
  только текста дала бы шкалу в 78% с подписью «40%».
- **Имена инструментов латинские.** Anthropic API принимает имя только по
  шаблону `^[a-zA-Z0-9_-]{1,64}$`. Всё видимое человеку осталось русским,
  русские имена параметров принимаются как синонимы.
- **Стиль хранится по ключу сессии.** При переезде на HTTP меняется только
  транспорт, инструменты трогать не придётся.
